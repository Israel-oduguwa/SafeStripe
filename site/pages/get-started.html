No installation

Try one hosted checkout.

The sandbox uses Express, Cloud Firestore and the published safestripe@0.3.0 package. It creates actual records in your dedicated Stripe sandbox.

Test secret keys still grant access to sandbox data and settings. Enter keys only in the website's masked fields. Never put them in an issue, screenshot or public recording.

  1. Connect your test keys.

    Use a dedicated Stripe sandbox's secret key and matching publishable key. Automatic setup creates the customer, prices and webhook destination.

  2. Open Hosted checkout.

    Pay with 4242 4242 4242 4242, a future expiry and a valid three-digit CVC. Use test details only.

  3. Wait for the verified receipt.

    Return to the workspace and inspect the payment checks. A redirect or connected badge alone is not proof of payment.

  4. Review and clean up.

    Use Your test records and cleanup when finished. Financial history remains in Stripe; cleanup does not erase it.

Your own application

Install the library.
Add only the drivers you use.

Use Node.js 22.19 or newer. The Stripe server SDK is included; consumers do not install it separately.

npm install safestripe

Choose your application dependencies
You use Add Requirement
Express npm install express express-rate-limit Authentication and server-approved billing terms
Next.js Your existing application Node runtime; worker outside request handlers
PostgreSQL npm install pg Durable database and migrations
MongoDB npm install mongodb Replica-set transaction support
Cloud Firestore npm install @google-cloud/firestore Server credentials and indexes
Local SQLite No database driver One active worker; local development
